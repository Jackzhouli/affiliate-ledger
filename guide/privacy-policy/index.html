Affiliate Ledger Privacy Policy

How Affiliate Ledger accesses, uses, stores, shares, and protects Google Ads campaign data and related information. Last updated: October 16, 2026.

1. Who We Are

Affiliate Ledger is a personal tool operated by its owner for affiliate marketing campaign organization and Google Ads keyword research. This website (https://tracker.opportunitiessite.com/) describes the tool and publishes this Privacy Policy. Contact: contact@opportunitiessite.com.

2. Scope

This Privacy Policy covers:

  • Information processed when Affiliate Ledger connects to Google Ads via the Google Ads API
  • Limited technical information that may be collected when you visit this website
  • How that information is used, stored, shared, retained, and protected

This informational website does not require user accounts to view the homepage or this policy.

3. Google User Data We Access

When the owner authorizes Affiliate Ledger to access a Google Ads account, the tool may access the following Google Ads data as needed to provide the features described on the homepage:

  • Campaign and ad group information (names, status, budgets, bids)
  • Keyword data, including match types and performance metrics
  • Ad creative and sitelink information used for campaign management
  • Account-level settings needed to execute requested changes
  • Basic account identifiers required to call the Google Ads API on behalf of the authorized account

Affiliate Ledger requests only the Google Ads API scopes and data necessary for keyword research, metrics review, and campaign organization. We do not request unrelated Google product data (for example Gmail content) for this tool.

4. How We Use Google User Data

Google Ads data accessed through the API is used only to:

  • Research and evaluate keywords for affiliate marketing campaigns
  • Review available advertising metrics
  • Organize and update campaign information based on the owner's instructions
  • Display or export that information into the owner's private working documents (such as Google Sheets) for the same purposes

We do not:

  • Sell Google user data
  • Use Google user data for advertising to other parties
  • Use Google user data to train generalized AI/ML models
  • Use Google APIs or Google user data to create or distribute AI-generated non-consensual intimate imagery (AI NCII)
  • Share Google user data with other end users of a public product (this is a personal tool)

5. Data Storage and Sharing

Campaign and keyword information processed by Affiliate Ledger is stored in the owner's private Google Sheets workspace (or equivalent private workspace controlled by the owner). No Google Ads campaign data is stored as a public database on this website.

Google user data is not shared with unaffiliated third parties, except as required to operate the tool through Google services the owner already uses (for example Google Ads API and Google Sheets), or when disclosure is required by law.

6. Website Visitors

If you only browse this website, we may receive standard server or hosting logs (such as IP address, user agent, and requested URL) from our hosting provider for security and reliability. We do not use that information to build marketing profiles.

7. Data Retention

Google Ads data kept in the owner's private workspace is retained only as long as needed for campaign research and organization, or until the owner deletes it. Authorization tokens can be revoked by the owner in their Google Account permissions at any time.

8. Security

We apply reasonable administrative and technical measures appropriate for a personal tool, including restricting access to the owner's accounts and using Google's OAuth / API authentication rather than storing Google passwords on this website.

9. Your Choices

The Google account owner can revoke Affiliate Ledger's access at any time through Google Account settings (third-party access / Apps with access to your account). After revocation, the tool will no longer be able to call the Google Ads API for that account. To request deletion of data stored in the owner's private workspace, email contact@opportunitiessite.com.

10. Children

Affiliate Ledger is not directed to children under 13, and we do not knowingly collect personal information from children.

11. Changes

We may update this Privacy Policy from time to time. The “Last updated” date at the top of this page will change when we do. Continued use of Affiliate Ledger after updates means the revised policy applies.

12. Contact

Questions about this Privacy Policy or data handling: contact@opportunitiessite.com.
